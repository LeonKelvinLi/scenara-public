# Language consistency — 0.8.4

The previous first-visit default selected Portuguese regardless of browser locale, while imported market titles/rules had no Portuguese translations. The remote translator was returning HTTP 429 and ignored long rules. Source outcome labels, trade directions and chart controls also bypassed localization.

New visits follow the browser locale, falling back to English for unsupported locales. Explicit choices persist. Market details include their own language selector and source requests carry the same locale. Late responses from a previous locale cannot populate the active source panels. Untranslated prose shows a localized pending state, with an explicit original-text control for resolution rules.

The cached corpus includes Portuguese titles and full rules for all 56 open markets at the time of capture, plus shared source metadata. New text uses local OPUS-MT inference with one int8 model resident at a time, a bounded cache, deduplicated background jobs and retry backoff. Hashes identify exact source text, changed rules invalidate stored translations, and numeric checks reject altered thresholds. Machine translations remain labelled and originals remain available. Source team/candidate names keep their identities; matchup templates preserve team and tournament names while translating labels.

Model packages are version-pinned and checksum-verified. No market text is sent to a translation API. The English-Portuguese and English-Chinese models come from the official Argos index and retain OPUS-MT's CC-BY 4.0 credit in the public translation notices. A Linux container using the backend dependencies peaked at 230 MiB while loading and using both languages in sequence, within the existing service's 512 MiB plan.

Validation: 37 PostgreSQL backend tests, including locale separation, exact-content cache keys and rule-change invalidation; 11 frontend locale regressions; TypeScript, lint and production export. Chrome verification covers the reported Iran market, English/Portuguese switching, reload persistence, source tabs, original-text controls, the simulation ticket and responsive layouts.
